# V1 Feature Scope & Exclusions

## Mandatory V1 Features
- [x] Authentication & Onboarding
- [x] ₹100,000 Virtual Wallet
- [x] Supported V1 Assets (BTC, ETH, SOL, XRP, BNB)
- [x] Live Market Prices & Price Ticker Stream
- [x] Market BUY & Market SELL
- [x] Simple Stop-Loss Orders
- [x] Holdings & Virtual Portfolio Valuation
- [x] Realised & Unrealised P&L Calculation
- [x] Portfolio Risk Score Meter (0-100)
- [x] Trading Discipline Score Meter (0-100)
- [x] AI Trade Coach Explanation Layer
- [x] RevenueCat Subscription & Paywall Architecture
- [x] Feature Flags & Remote Config Abstraction
- [x] Account Deletion & Privacy Controls

## Excluded from V1 (Do NOT Build)
- Real-money trading, deposits, or withdrawals
- Crypto wallet or exchange account connection
- Futures, leverage, or short selling
- Copy trading, social feeds, or squads
- Complex technical analysis platforms
- Self-training production AI
