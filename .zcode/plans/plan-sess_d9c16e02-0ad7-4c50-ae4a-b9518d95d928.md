# Liquid Glass Aurora Redesign — Implementation Plan

## ⚠️ Critical discovery that shapes this plan
There are **two files both declaring `class DashboardScreen`**:
- `lib/features/home/presentation/home_screen.dart` (248 lines, **simpler**) — contains the test-asserted strings `'CryptoEdu Simulator'`, `'Virtual Portfolio Equity'`, `'Supported V1 Markets'`. The router (`app_router.dart`) imports this file and routes `/home` to it. `home_screen_test.dart` asserts these strings and currently passes.
- `lib/features/home/presentation/dashboard_screen.dart` (767 lines, **Bento premium**) — the showcase screen from the previous agent. **It is NOT actually wired to `/home`** (would cause a duplicate-class compile error otherwise). It uses `'VIRTUAL EQUITY'` / `'Live Markets'` strings no test depends on.

**Conclusion:** The premium Bento dashboard is dead code. What you actually see on your OPPO device when you open the app is the **simpler `home_screen.dart`**. That's a big reason the UI "doesn't look good" — the rich work was never connected. The redesign will make `home_screen.dart` itself premium.

## What you'll get (Liquid Glass Aurora direction)
- **Base**: deep obsidian canvas with a **slowly shifting aurora gradient** (emerald→cyan→indigo, very subtle, ~12s drift) replacing the neon-dominant look. Depth via blur, not heavy shadows.
- **Surfaces**: frosted-glass cards (rounded 28px, hairline translucent borders, soft inner highlight). One unified `GlassCard` used everywhere — no more 3 different card styles.
- **Type**: keep Outfit/Inter; switch numeric/prices to tabular figures so digits align. Restrained glow only on the focal element.
- **Loader**: replace the 1.6MB video + GIF with one **code-drawn `AuroraLoader`** (CustomPainter: 3 rising candle bars pulsing cyan→emerald in sequence + subtle count-up). ~0KB, instant start, theme-aware, runs at any size.
- **Consistency**: every screen gets the aurora background; every "asset row" becomes one shared `AssetListTile` widget.

## Implementation steps (ordered to keep tests green at each step)

### Step 1 — Theme foundation (additive, no breakage)
Edit `lib/app/theme/app_theme.dart`:
- Add `AppSpacing` token class (`xs=4, sm=8, md=12, lg=16, xl=20, xxl=28, xxxl=40`) to kill ad-hoc spacing.
- Add `AppGradients.auroraShift` (animated-ready multi-stop), `AppGradients.glassFrost` surface gradient, `AppRadii` (card=24, pill=28, chip=12).
- Add aurora palette: `auroraEmerald`, `auroraCyan`, `auroraIndigo` (softer than current neon).
- Leave existing `AppColors.*` tokens intact (don't break 23 migrated files).

### Step 2 — Aurora background (replaces ambient mesh as the default)
New `lib/shared/widgets/aurora_background.dart`:
- `AuroraBackground({Sentiment? sentiment, Widget? child})` — slowly drifting aurora blobs (emerald/cyan/indigo) via 2–3 animated `CustomPainter` circles with heavy blur. Optional sentiment tints the aurora.
- Uses a single `TickerProvider` with **disposable** controller. Critically: provide a way to disable animation in tests (a static `enabled` flag) so any future `pumpAndSettle`-based test doesn't hang (lesson from the earlier regression).
- This is the new shared background for ALL screens.

### Step 3 — Code-drawn loader (`AuroraLoader`)
New `lib/shared/widgets/aurora_loader.dart`:
- `AuroraLoader({double size=64, String? label})` — CustomPainter drawing 3 ascending candle bars that pulse in sequence (cyan→emerald), with a faint orbital ring.
- **Repurpose the existing `CryptoLoadingIndicator` class**: keep the class name + `size` param (test contract) but repoint its `build` to render `AuroraLoader`. This keeps `shared_components_test.dart` green AND makes `PrimaryButton` loading use the new mark.
- Deprecate (don't delete yet) `BitcoinLoader`/`BitcoinLoadingOverlay`/`AdaptiveLoader` — keep them compiling so nothing breaks; migration to `AuroraLoader` happens in the screen rewrites.

### Step 4 — Shared building blocks (new, additive)
New `lib/shared/widgets/glass_card.dart`:
- `GlassCard({child, padding, onTap, borderColor, blurStrength})` — the ONE frosted card. Uses `BackdropFilter(blur 18)` + `glassFrost` gradient + hairline border. When `onTap` set, wraps in `SpringScaleButton` + subtle press highlight. This replaces ad-hoc card containers.
New `lib/shared/widgets/asset_list_tile.dart`:
- `AssetListTile({asset, currentPrice?, changePercent?, onTap, showSparkline, showChevron})` — the ONE asset row. Tinted monogram avatar, name, symbol, tabular price, change chip, optional mini `LiquidGlowSparkline`. Used by Dashboard, Markets, TradeEntry.
